# Project preferences

- Leave testing to the user. Do not use desktop/computer-use tools for testing or verification, and do not run automated tests or manual UI checks unless the user explicitly requests them. Make the requested code changes and report what changed without launching or interacting with the app.

- Use the **Sosumi MCP** (`mcp__sosumi__searchAppleDocumentation` and `mcp__sosumi__fetchAppleDocumentation`) as the first source for Apple documentation, including Swift, SwiftUI, macOS frameworks, and Human Interface Guidelines. The user may refer to it as “susomi.” Fall back to official Apple web documentation only if Sosumi is unavailable or does not cover the topic.
